PARADISE NURSERY SHOPPING APPLICATION
=====================================

Project Overview
----------------
Paradise Nursery is a front-end shopping application built using React.

The application allows users to browse a selection of houseplants,
add plants to a shopping cart, change item quantities, remove items,
and view the total cost of their shopping cart.

This project demonstrates the use of React components, React Hooks,
Redux state management, ES6 JavaScript, and responsive UI development.


FEATURES
--------

1. Landing Page
   - Displays the Paradise Nursery company name
   - Background image
   - Information about the company
   - Get Started button to navigate to the product listing page

2. Product Listing Page
   - Displays at least six houseplants
   - Plants are organized into multiple categories
   - Each plant displays:
       * Plant image
       * Plant name
       * Price
       * Add to Cart button
   - Shopping cart icon displays the current number of items

3. Shopping Cart Page
   - Displays plants added to the cart
   - Displays plant image and name
   - Displays unit price
   - Displays quantity
   - Displays total price for each plant
   - Displays total number of plants
   - Displays overall cart cost
   - Increase quantity button
   - Decrease quantity button
   - Delete/remove item button
   - Continue Shopping button
   - Checkout button

INSTALLATION
------------

1. Clone the repository:

   git clone <your-github-repository-url>

2. Go to the project directory:

   cd paradise-nursery-shopping

3. Install the required dependencies:

   npm install

4. Start the development server:

   npm run dev


RUNNING THE APPLICATION
-----------------------

Run:

   npm run dev

Vite will display a local URL, normally similar to:

   http://localhost:5173/

Open the URL in a web browser.


BUILDING THE APPLICATION
------------------------

To create a production build:

   npm run build
